Cara Upload Hostinger & Instal di Android

Setelah Anda memilih "Buat website kosong" di Hostinger:

  1. Buka File Manager Hostinger lalu masuk ke folder public_html.
  2. Buat file bernama index.html dan tempelkan kode halaman ini (plus api.php jika ingin API Key tersimpan otomatis di server).
  3. Buka domain Hostinger Anda di browser Google Chrome HP Android.
  4. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas Chrome, lalu pilih "Tambahkan ke Layar Utama" (Install App).

Konfigurasi Gemini API Key

Tips Hostinger: Jika Anda hanya mengupload index.html ke Hostinger, masukkan API Key Google AI Studio Anda di bawah ini (cukup sekali saja, akan tersimpan di HP Anda). Jika Anda juga membuat api.php di Hostinger, kolom ini boleh dikosongkan!

Dapatkan API Key gratis di aistudio.google.com.
